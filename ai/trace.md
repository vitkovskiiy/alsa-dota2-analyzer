# Trace AI Interaction: Alsa API Foundation

## Промпт 1: Ініціалізація архітектури (Fastify + TypeScript)
**Промпт інженера:** 
> Згенеруй базову інфраструктуру сервера на фастифай з використанням тс сервер повинен бути розділеним на точку входу із підтримкою грац шутдаун та фабрику додатка із налаштованим логгером. Також додай базовий роут хелс та налаштуй компілятор тайпскрипт і скрипти запуску з підтримкою тсх для гарячого перезавантаження в розробці.

**Дії та вихід AI:** 
- Створено `src/app.ts`, `src/server.ts`.
- Оновлено `package.json` (додано `fastify`, `tsx`, `typescript`).
- Згенеровано строгий `tsconfig.json` (ES2022, Node16 module resolution).

**Зрізані кути (Audit 1):**
AI згенерував шаблонний код, проте не додав:
1. Юніт-тестування (немає `Vitest`/`Jest` та тестів через `fastify.inject`).
2. Не запровадив строгу валідацію змінних середовища (env vars) через `zod` на старті.
*Виправлення (Action Item):* Звужено специфікацію поточного етапу до виключно ініціалізаційної частини серверу; валідацію та тести винесено в техборг наступних ітерацій.
